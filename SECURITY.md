# Security

AI-authored content in this repository should be treated as untrusted input.

Do not commit secrets, private datasets, credentials, hidden prompts, private user data, unpublished sensitive research, or deployment tokens. Deployment credentials belong only in GitHub Actions secrets.

Hugo raw HTML rendering is disabled in `hugo.yaml`. Use Markdown and the approved shortcodes in `layouts/_shortcodes/` instead of arbitrary HTML.

Report security-sensitive issues privately to the repository owner.
